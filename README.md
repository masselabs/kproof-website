# Korean Privacy ID — 프라이버시ID

한국 모바일 신분증 기반 개인정보 보호형 인증 제품의 출시 전 소개 사이트입니다. HTML, CSS, Vanilla JavaScript만 사용하며 빌드나 패키지 설치가 필요하지 않습니다.

## 로컬 실행

이 디렉터리에서 다음을 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

접속 주소: http://127.0.0.1:4173/

## 파일

- `index.html`: 한국어 기본 콘텐츠와 시맨틱 페이지 구조
- `css/styles.css`: 색상 토큰, 제품 중심 레이아웃, 반응형 스타일
- `css/typography.css`: 제목·리드·본문·보조 안내의 공통 글자 크기, 대비, 행간과 반응형 간격
- `js/app.js`: 국·영문 콘텐츠, 언어 선택 유지, 모바일 메뉴, 스크롤 연출과 증명·이용 단계 선택
- `assets/logo.svg`, `assets/logo-inverse.svg`, `assets/favicon.svg`: D 내부의 여백이 i로 읽히는 심벌과 어두운 배경용·파비콘 버전
- `assets/mobile-id.svg`: 인물 영역과 보안 문양을 포함한 자체 제작 신분증 예시 그래픽
- `assets/fonts/`: 로컬 Pretendard Variable v1.3.9와 SIL OFL 1.1 라이선스
- `qa/check-source.cjs`: 번역 키, 내부 링크, 로컬 자산, 미구현 URL, 외부 링크 속성 검사
- `qa/checks.js`: 로컬 브라우저에서 실행하는 반응형·메뉴·FAQ·인터랙션 검사

## 디자인

타이포그래피는 제목의 크기를 절제하고 설명을 확대해 읽는 흐름을 조정했습니다. 주요 설명과 본문은 16~22px, 보조 안내는 12~14px를 중심으로 사용합니다. 증명 결과·단계 제목·전달 정보 구분은 굵기와 대비로 강조하며, 신분증 그림 안의 축소된 표기는 별도 크기를 사용합니다. 앱 예시의 높이와 문단 폭도 확대된 글자에 맞춰 조정했습니다.

2026-10-25 후속 피드백에 따라 한국어 문구를 기능과 이용 목적 중심으로 수정하고, 로고·신분증 이미지·섹션별 스크롤 효과를 개선했습니다.

- 첫 화면은 검정 배경에서 개인정보 → 정보 가림 → 필요한 증명 결과 순으로 변합니다. 브라우저의 기본 스크롤을 유지하며 역방향 스크롤도 지원합니다.
- 흰색 증명 비교 화면에서 연령·지역·자격을 선택하면 서비스에 전달할 결과 예시가 바뀝니다. 이용 방법은 3단계 탭과 앱 화면이 연동됩니다.
- 검정·흰색·실버·코발트 화면을 큰 타이포그래피와 여백으로 연결합니다. 로고는 빨강 `#CD2E3A`과 파랑 `#0047A0`을 사용하며, 어두운 배경에서는 D를 흰색으로 표시합니다. 기존 증명 포인트 색상은 유지합니다.
- 선택된 심벌은 D 내부의 여백으로 i를 표현해 ID와 보호된 개인을 결합합니다. 헤더·앱 화면·연결 흐름·브랜드 소개·개발자 영역·푸터·파비콘에 동일한 형상을 적용했습니다. 파비콘은 브라우저의 밝고 어두운 테마에 맞춰 대비를 조정합니다.
- 신분증 이미지는 인물 영역, 마스킹된 정보와 곡선 패턴을 포함한 자체 제작 예시입니다. 정부 로고, 실제 번호, 스캔 가능한 코드는 포함하지 않습니다.
- 첫 화면 이후 정보 항목 축소, 이용 단계 자동 전환과 스캔, 연결선 확장, 심벌 확대·포인트 드러남과 글자 채움, 개발자 검증 흐름 그리기가 이어집니다.
- 이용 단계의 고정 화면은 너비 901px·높이 850px 이상에서 동작합니다. 직접 선택한 단계는 스크롤이 충분히 진행될 때까지 유지합니다.
- 모든 제품 그림은 HTML/CSS/SVG이며 외부 이미지나 UI 라이브러리가 필요하지 않습니다. 화면은 실제 인증 기능이 없는 설명용 콘셉트입니다.
- 탭은 방향키·Home·End로 조작할 수 있습니다. 움직임 감소 설정이나 낮은 화면에서는 고정 스크롤 연출 대신 정적인 구성을 제공하며, JavaScript 없이도 기본 한국어 본문을 읽을 수 있습니다.

## 한국어 문구 참고

- [Apple 한국어 개인정보 보호](https://www.apple.com/kr/privacy/): 제품·기능을 먼저 제시하고 작동 방식을 설명하는 구조를 참고했습니다.
- [토스뱅크](https://www.tossbank.com/): 구체적인 이점과 행동을 짧게 전달하는 방식을 참고했습니다.
- [카카오뱅크](https://www.kakaobank.com/): 서비스의 역할을 평이한 한국어로 전달하는 톤을 참고했습니다.
- 문구를 복사하지 않고 출시 전 상태에 맞춰 새로 작성했습니다. 모바일 신분증 [공식 소개](https://www.mobileid.go.kr/mip/hps/main.do)의 카드 구성은 시각 참고로만 사용했습니다.

## 확인한 레퍼런스

- [ZKPassport](https://zkpassport.id/): 실제 페이지의 기능 설명, 사용자 단계, 개발자 안내, FAQ 구조를 확인했습니다. 해당 서비스의 현재 지원 범위, 주장, 이미지와 문구는 이 제품으로 옮기지 않았습니다.
- [대한민국 모바일 신분증 디자인 가이드](https://dev.mobileid.go.kr/mip/dfs/useguide/mdGuide.do?guide=designguide): 최초 접속에는 로그인 안내가 표시되었으나 이후 Chrome에서 본문을 확인했습니다. 공식 BI 변형 금지, 전용 버튼 적용 범위와 제출정보 확인 절차를 검토했습니다. 본 사이트에는 정부 BI, 전용 인증 버튼, 실물 신분증이나 정부 인증 마크를 사용하지 않습니다.
- [Pretendard](https://github.com/orioncactus/pretendard): 공식 저장소의 폰트를 로컬 제공하며 원문 라이선스를 포함합니다. 폰트 CDN이나 추적 스크립트 호출이 없습니다.

## 콘텐츠와 링크 관리

모든 번역은 `js/app.js`의 `translations` 객체에서 관리합니다. 기본 언어는 한국어이며, 언어를 선택하면 `korean-privacy-id-language` 키로 localStorage에 저장합니다. 저장소가 차단되어도 현재 페이지의 언어 변경은 작동합니다. `<html lang>`, 페이지 제목, 설명, Open Graph 메타데이터와 접근성 레이블을 함께 변경합니다.

초기 한국어 HTML은 JavaScript 없이도 본문을 읽을 수 있도록 작성되어 있습니다. 문구 변경 시 HTML의 한국어 기본값도 함께 수정하세요.

SDK, 개발자 문서, 앱스토어, API, 제품 전용 저장소, 개인정보처리방침과 약관의 URL은 `pendingUrls` 객체에 빈 문자열로 남겨두었습니다. `TODO`를 따라 실제 전용 리소스가 공개된 후에만 연결하세요. 현재 UI의 준비 중 항목은 링크가 아닙니다.

이 사이트는 정적인 소개 페이지입니다. 증명 생성, 인증 요청, 개인정보 입력, 로그인 및 데이터 전송 기능이 없습니다. 결과 화면은 항상 설명용 예시로 표시됩니다. 해외 사용은 서비스의 증명 수용 여부에 따르며, Human Passport는 연동 방향의 예시입니다.

## 검증

소스 검사:

```sh
node qa/check-source.cjs
node --check js/app.js
```

로컬 사이트를 연 Chrome의 DevTools Console에서 다음을 실행하면 360, 390, 768, 1024, 1440px에서 한국어와 영어를 점검합니다. 외부 전송 없이 같은 로컬 페이지를 임시 iframe으로 열고 제거합니다.

```js
await import('/qa/checks.js').then(module => module.checkSite())
```

검증 이력과 실제 실행 범위는 `qa/verification.md`에 기록했습니다.

배포, 도메인 연결, 인증 API, 앱스토어 등록은 이 작업에 포함하지 않습니다.
