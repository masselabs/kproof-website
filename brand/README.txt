KProof Brand Kit — v1.0 / 2026-10-27

Start here
Open brand/index.html in a browser. The guide works offline, including individual
asset links. Automatic color copying depends on browser clipboard support.

Identity
The product name is KProof (Korea + Proof), pronounced 케이프루프.
The custom vector wordmark reads KPROOF. Use K as the compact symbol.
Do not redraw, stretch, re-space, rotate or recolor the supplied marks.
Keep at least 1/4 of the mark's height clear on every side.
Minimum screen size: wordmark 88px wide; symbol 16px tall.

Color
Blue #0047A0 / Red #CD2E3A / Black #09090B / White #FFFFFF / Paper #F5F5F7.
Color values are sRGB screen references, not certified print specifications.
Color wordmark: light neutral backgrounds. Inverse wordmark: dark backgrounds.
Use the black/white exports for monochrome reproduction.

Files
brand/assets/ — 14 SVG files: 4 wordmarks, 4 symbols, 1 app icon,
1 adaptive favicon, 2 social templates and 2 ambient curves.
brand/tokens.json — source design values.
css/tokens.css — generated CSS custom properties shared with the website.
assets/fonts/ — Pretendard Variable WOFF2 and SIL Open Font License 1.1.

The wordmarks and symbols are outlined vectors and require no font installation.
Social templates are editable SVGs at 1200 x 630. Apply Pretendard when exporting;
the WOFF2 font is supplied for web use. Use a compatible installed desktop font
version for design applications. Export templates to PNG/JPEG for social platforms.
The app icon is a 512 x 512 square vector master without rounded corners; generate
the required raster sizes and let the target platform apply its icon mask.

Usage
Use these assets when presenting KProof. Do not imply government certification,
partnership or endorsement. Keep launch status and supported capabilities accurate.
Brand artwork is provided for KProof-related use; the font has its separate OFL
license. This kit does not grant a general license to the KProof brand.
